# ① 검출 + 전체 흐름 실험 (C4, D01, D02, 오경보, C6)

- 질문 1 (C4): 실제 파이프라인 (검출 박스 → 대상 선택 → 상태 판별) 에서 대상의 상태를 맞히는가
- 질문 2 (C1, C2): 검출 모델이 신호등, 특히 **차량 신호등** 을 찾는가
- 기간: 2026-10-25 ~ 2026-11-01, DESKTOP (WSL, RTX 5070 Ti Laptop 12GB)
- 상태 판별 단독 실험 (정답 박스 기준) 은 `state_classification.md`

## 1. 모델 정의

| 이름 | 단계 | 종류 | 학습 여부 | 내용 |
|---|---|---|---|---|
| COCO | ① 검출 | `yolo26n` | **학습 안 함** (COCO 사전학습 그대로) | COCO `traffic light` (class 9) 만 사용. 차량·보행자·측면 구분 없음 |
| det_vehicle_other | ① 검출 | `yolo26n` | COCO 사전학습 → AI Hub train 7,000장으로 **파인튜닝** | 2클래스: 0 vehicle (차량 신호등) / 1 other (측면·보행자·기타). 사용할 때 `--det-classes 0` |
| HSV | ③ 판별 | 규칙 `classifier.py` | 학습 모델 아님 | E01 |
| E02 / E03 | ③ 판별 | `yolo26n-cls` | **파인튜닝** | 6클래스 / 7클래스 (+NONE). E03 의 NONE 은 UNKNOWN 으로 바꿔 selector 에 넘김 |

- C4 = COCO 검출 + 판별기 / **C4D** = det_vehicle_other 검출 + 판별기 (판별기 가중치는 같음)

## 3. C4 — COCO 검출 + 판별기 비교 (2026-10-25)

| ID | 판별기 | 정확도 (대상 있음) | det_miss | wrong_box | wrong_state | 오경보 (대상 없음) | 판별+선택 |
|---|---|---|---|---|---|---|---|
| C4-HSV | HSV (규칙) | 23.6% | 71.2% | 0.6% | 4.6% | 5.3% | 0.10 ms |
| C4-E02 | E02 | 31.5% | 67.9% | 0.4% | 0.2% | 17.1% | 2.29 ms |
| C4-E03 | E03 | 30.8% | 68.6% | 0.2% | 0.4% | 10.5% | 2.11 ms |

- 검출기가 정답 대상을 찾은 비율 **23.1%** (329 / 1,424) → 판별기와 관계없이 det_miss 68~71%
- 검출만 되면 학습 판별기는 대부분 맞힘 (329장 중 틀린 수: HSV 74, E02 9, E03 8)
- 판별기 결정: **E03** (E02 와 정확도 비슷, 오경보 10.5% < 17.1%)
- **병목은 검출** → 검출 베이스라인 측정

## 4. D01 — COCO 검출 베이스라인 (C1, C2)

| ID | conf | 기준 | Recall | Precision | 검출 수 |
|---|---|---|---|---|---|
| D01 | 0.25 | C1 모든 신호등 | 12.0% | 47.3% | 2,619 |
| D01 | 0.25 | **C2 차량 신호등** | **16.9%** | **29.2%** | 2,619 |
| D01b | 0.05 | C2 차량 신호등 | 35.1% | 10.1% | 15,851 |

- 크기별 차량 신호등 Recall (D01): 작음 (< 32²) 3.2% / 중간 (< 96²) 26.9%
- conf 를 0.05 까지 내려도 차량 신호등 65% 를 못 찾고, Precision 이 10% 로 떨어짐
- 보행자 신호를 차량 신호등보다 더 잘 잡음 (D01b 59.3% vs 35.1%) → COCO 클래스 구조로는 구분 불가
- 결정: **검출 파인튜닝** (설정 조정으로는 한계)

## 8. 오경보 분석 (C4D-E03, 대상 없음 76장 중 22장)

| 원인 | 장수 | 내용 |
|---|---|---|
| AI Hub `etc` 신호 (정의 밖 상태) | 17 | 황색 점멸 → YELLOW, 적색 + 화살표 2개 → RED_LEFT, 3구 화살표형 등. 대부분 **보이는 신호와 맞는 예측** |
| 실제 오검출 | 3 | RD_1543: 측면·보행자 신호등을 vehicle 로 검출 → RED |
| selector `min_area` 300 경계 | 2 | RD_1564: 정답 박스 200px² 는 탈락, 검출 박스는 조금 커서 통과. 상태는 맞음 |

- 평가 기준 보완 (A안, 모델 변경 없음): `etc` 신호만 있는 이미지 (etc-only 49장) 를 분리해 `fa_clean` 열로 따로 집계 (`eval_flow.py`)
- clean 27장 기준 실제 오경보 3장 (11.1%). 표본이 작아 참고용
- 주행 관점: 황색 점멸 → YELLOW (감속), 적색 + 화살표 → 정지 쪽 → 대부분 안전한 방향
