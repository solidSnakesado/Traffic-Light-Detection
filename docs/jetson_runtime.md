# 실행 장치 실험 — 젯슨 오린 나노 슈퍼 + TensorRT

- 질문: 휴대용 실행 장치 (젯슨) 에서 DESKTOP 과 **같은 결과** 를 실시간에 가깝게 낼 수 있는가
- 기간: 2026-11-08
- 환경 구성 절차는 `setup/jetson_jp72.md`

## 1. 조건

| 항목 | 젯슨 | DESKTOP (비교 기준) |
|---|---|---|
| 장치 | Orin Nano Super, 전원 모드 MAXN_SUPER, NVMe | RTX 5070 Ti Laptop 12GB (WSL) |
| 소프트웨어 | JetPack 7.2.1 (CUDA 13.2, TensorRT 10.16.2), torch 2.15.0+cu132 | torch 2.14.1+cu130 |
| ultralytics | 8.4.175 | 8.4.175 (같은 버전) |
| 가중치 | DESKTOP 에서 학습한 `best.pt` 그대로 (scp 로 복사) | 같음 |
| 모델 | ① det_vehicle_other (파인튜닝) `--det-classes 0` / ③ E03 (파인튜닝) / ② selector 기본값 (규칙) | 같음 |
| 영상 | `drive.mp4` 1920×1080, 60 fps, 15,797프레임 | 같음 |
| 측정 | `tools/record_states.py` (검출 + 판별 + 선택), 첫 프레임 (초기화) 제외 **중앙값** | 같음 |

- 코드는 두 장치가 같음. 다른 것은 실행 환경과 모델 파일 형식 (`.pt` / `.engine`) 뿐 (`--model` 인자만 바꿈)

## 2. TensorRT 엔진 변환

| 항목 | 내용 |
|---|---|
| 스크립트 | `tools/export_engine.py` (Ultralytics `export(format="engine")`, 이름에 입력 크기 포함) |
| 정밀도 | FP16 (기본) |
| 검출 엔진 | `best_736x1280.engine` (세로 736 × 가로 1280), 약 7분 |
| 판별 엔진 | `best_224x224.engine`, 약 5분 |
| 장치 고정 | 엔진은 만든 GPU + TensorRT 버전에서만 동작 → 젯슨에서 만들고 젯슨에서만 사용. JetPack 이 바뀌거나 `best.pt` 가 바뀌면 다시 만듦 |
| 입력 크기 고정 | 엔진은 입력 크기가 정해짐. 직사각형 736×1280 = 1920×1080 을 1280×720 으로 줄이고 32의 배수로 맞춘 크기 → 여백 최소 |

- 변환은 **속도 목적** 만 있음. 결과 (상태) 가 바뀌지 않는지 반드시 비교 (4장)

## 3. 속도

| 구성 | ms/프레임 (중앙값) | fps | 측정 범위 |
|---|---|---|---|
| PyTorch `.pt` | 69.5 | 14.4 | 300프레임 |
| TensorRT 정사각형 1280×1280 + E03 엔진 | 52.1 | 19.2 | 300프레임 |
| TensorRT 직사각형 736×1280 + E03 엔진 | 34.7 | 28.8 | 300프레임 |
| **TensorRT 직사각형 736×1280 + E03 엔진** | **27.8** (평균 30.1) | **약 36** (평균 33.2) | **전체 15,797프레임** |
| (비교) DESKTOP PyTorch `.pt` | 9.7 (평균 11.9) | 84.2 (평균) | 전체 |

- 정사각형 엔진이 느린 이유: 16:9 영상을 정사각형에 넣으면 위아래 여백까지 전처리·추론
- 검출 시간 내역 (직사각형 엔진): 전처리 **18.5 ms (CPU)** / 추론 7.7 ms / 후처리 3.8 ms. 영상 읽기 약 7 ms 별도
- 300프레임 측정이 전체보다 느린 것은 시작 직후 구간 (워밍업) 의 비중이 크기 때문

## 4. 결과 비교 (젯슨 TensorRT 직사각형 vs DESKTOP PyTorch, 전체 영상)

| 비교 | 같은 프레임 | 비율 |
|---|---|---|
| 원시 상태 (`state`) | 15,784 / 15,797 | 99.92% |
| 검출 수 (`n_det`) | 15,681 / 15,797 | 99.27% |
| **smoother 확정 상태** | **15,797 / 15,797** | **100%** |

- 원시 상태가 다른 13프레임은 원래 흔들리던 구간 (120초 황색 + 좌회전, 248~250초 먼 적색, 상태 경계 프레임) → FP16 의 작은 수치 차이가 경계에서만 나타남
- 300프레임 비교 (PyTorch, 정사각형 엔진) 도 원시 상태 300 / 300 같음
- ⑤ 제어에 넘어가는 확정 상태는 두 장치가 완전히 같음 → **젯슨을 실행 장치로 사용 가능**
